## 🛡️ سجل التحسينات والإصلاحات البرمجية (Changelog v22)

### 1. تطهير منطق عرض المنتجات والمتاجر (Pure Supabase Pipeline):
- **إزالة البيانات الوهمية كلياً:** تم حذف حقن أي منتجات أو قصص تجريبية من `web/js/customer-home-logic.js` و `web/js/customer-home-ui.js`.
- **المصدر الحصري:** Supabase هو المصدر الوحيد والنهائي للبيانات. في حال كانت الجداول فارغة تظهر الواجهة حالة فارغة أنيقة ونظيفة بدون أي صور أو متاجر وهمية.
- **تصفية المتاجر المعتمدة:** حصر دليل المتاجر فقط على المتاجر المسجلة في Supabase والتي تمت الموافقة عليها بحالة `APPROVED` أو `ACTIVE`.

### 2. ترقية الـ Service Worker وإبطال الكاش القديم:
- ترقية إصدار الكاش إلى `zalo-v22-fix` لفرض مسح أي كاش قديم وإجبار المتصفحات وتطبيق PWA على تنزيل وتطبيق الكود الجديد فوراً.

### 3. تأمين بوابة الذكاء الاصطناعي (Gemini AI Proxy):
- الاعتماد التام على متغيرات البيئة `process.env.GEMINI_API_KEY` وإزالة أي مفاتيح صريحة، مع إرجاع استجابة 500 في حال عدم تعيين المفتاح.

### 4. مزامنة تطبيق أندرويد (Android Asset Sync):
- مزامنة كافة ملفات وموارد الويب مع مسار `app/src/main/assets/web/` لضمان تطابق كامل 1:1.

## ⚙️ المتطلبات الأساسية (Prerequisites) — للاستخدام الداخلي فقط
لتشغيل هذا المشروع بنجاح، يجب توفير المكونات التالية (تُمنح فقط للفريق الداخلي المعتمد):
- **Node.js** (v20 أو أعلى)
- **PostgreSQL** (v15 أو أعلى)
- **Android Studio** (لمطوري التطبيق)
- **ملف `.env`** مُوقّع من الإدارة (يحتوي على مفاتيح JWT، قاعدة البيانات، وبوابات الدفع). هذا الملف لا يُرفع إلى المستودع العام.

## 🚀 خطوات التثبيت (للفريق الداخلي فقط)
*ملاحظة أمنية هامة: لا يمكن تشغيل المشروع دون الحصول على مفاتيح البيئة من فريق DevSecOps عبر قناة آمنة.*

1. استنساخ المستودع (بإذن مسبق).
2. تثبيت تبعيات الباك-إند وتشغيله:
   ```bash
   cd backend
   npm install
   npm run start:dev
   ```

3. تثبيت تبعيات الواجهة الأمامية (اختياري لتشغيل الاختبارات):
   ```bash
   cd ../web
   npm install
   ```
4. إعداد قاعدة البيانات المحلية:
   ```bash
   psql -U postgres -d zalo_db -f database/schema.sql
   ```
5. فتح الويب: استخدام Live Server لتشغيل web/index.html.
6. بناء الأندرويد: يتطلب توقيع إصدار بمفاتيح موقعة من قبل الإدارة.
